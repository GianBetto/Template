# Hub Template HTML5 & CSS3

> Raccolta di modelli web editoriali, moderni ed essenziali sviluppati con HTML5 semantico, CSS3 moderno (senza framework esterni) e JavaScript vanilla. Ogni template include il supporto nativo al doppio tema (Chiaro / Scuro), layout responsive e componenti interattivi.

## ✨ Caratteristiche Principali

- 🎨 **Design Moderno & Curato**: Palette colori armoniose, micro-interazioni e cura tipografica.
- 🌓 **Tema Chiaro & Scuro (Dark Mode)**: Switch dinamico integrato con salvataggio preferenze in `localStorage` e default in tema chiaro.
- 📱 **Completamente Responsive**: Navigazione adattiva con menu hamburger mobile in Pure JS/CSS.
- ⚡ **Zero Dipendenze Pesanti**: Realizzato in HTML5, Vanilla CSS3 (CSS Variables, Flexbox, Grid) e Vanilla JavaScript.
- ♿ **HTML Semantico & Accessibilità**: Tag semantici (`<header>`, `<main>`, `<article>`, `<nav>`, `<footer>`) e attributi ARIA per la massima compatibilità SEO e screen reader.

## 🚀 Utilizzo

1. Clona il repository localmente:
   ```bash
   git clone https://github.com/gianbetto/Template.git
   ```
2. Apri il file `index.html` nel browser per esplorare l'Hub oppure naviga direttamente all'interno delle cartelle dei singoli template per riutilizzare il codice sorgente nei tuoi progetti.
